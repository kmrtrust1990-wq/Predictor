# Crash Game RNG Simulator & Tester

This is a Python Flask web application that simulates a Provably Fair Crash game algorithm (like Aviator) using SHA-256 and HMAC. It allows you to generate historical round data and test the prediction accuracy of your target strategy.

## How to Run

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open your browser and navigate to `http://127.0.0.1:5000`.
